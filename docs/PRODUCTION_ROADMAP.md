# AgentScale Production Roadmap (12–24 months)

## Q1 — Category validation

- 3–5 design partners (regulated + high agent volume)
- Langfuse / OpenTelemetry integration for live metrics
- SSO (SAML/OIDC) for enterprise
- SOC 2 Type I preparation

## Q2 — Platform depth

- Agent Marketplace (internal templates)
- Multi-agent workflow certification
- Vector KB ingestion (Supabase pgvector or external)
- Policy pack versioning with bulk re-certification
- A/B testing for prompts in staging

## Q3 — Scale & compliance

- EU data residency option
- Custom compliance workflows (banking, healthcare)
- API for CI/CD agent registration
- Workforce planning (cost forecast, capacity)
- Mobile-friendly approver experience

## Q4 — Category leadership

- Partner integrations (Salesforce, ServiceNow, Zendesk)
- External certified agent marketplace (ISV)
- AI improvement recommendations engine (auto-retrain suggestions)
- Advanced analytics (value attribution, FTE equivalence)

## Technical debt paydown

- Background jobs (Supabase Edge Functions or Inngest)
- Full-text search on agents + audit logs
- Rate limiting + WAF on public endpoints
- Disaster recovery + PITR documentation
